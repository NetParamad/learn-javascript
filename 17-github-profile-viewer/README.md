# 17 GitHub Profile Viewer

## ภาษาไทย
พิมพ์ username -> ดู followers / จำนวน repo + 5 repo ล่าสุดพร้อมดาว

โน้ต: `fetch` 2 ต่อ, เช็ค `res.ok` + 404, `map` ก่อน render

เปิด: `index.html` ใน browser (ต้องมีเน็ต)

## English
Type a username -> see followers / repo count + 5 latest repos with stars.

Note: chained `fetch`, `res.ok` + 404 handling, `map` before render

Open: `index.html` in a browser (needs internet)
