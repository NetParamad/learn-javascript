# Learn JavaScript / เรียน JavaScript

## ภาษาไทย
Repo ทบทวน JS แยกโฟลเดอร์ละเรื่อง เน้นตัวอย่างรันได้สั้นๆ

- `01-variables` ถึง `09-array-methods`: รันด้วย `node example.js`
- `10-dom-basics`, `11-events`, `13` ถึง `17`: เปิด `index.html` ใน browser
- `12-fetch-api`: รันด้วย `node example.js` (Node 18+)

เป้าหมาย: `fetch` + แสดงผล ดูที่โฟลเดอร์ `13-mini-project-fetch-display`

โปรเจคใช้งานจริง:
- `14-todo-app` — Todo + localStorage
- `15-product-search` — ค้นหา + กรองสินค้า (API)
- `16-weather-app` — เช็คอากาศรายเมือง (API)
- `17-github-profile-viewer` — ดูโปรไฟล์ GitHub (API)

## English
JS review repo, one folder per topic, short runnable examples.

- `01-variables` to `09-array-methods`: run with `node example.js`
- `10-dom-basics`, `11-events`, `13` to `17`: open `index.html` in a browser
- `12-fetch-api`: run with `node example.js` (Node 18+)

Goal: `fetch` + render, see `13-mini-project-fetch-display`

Real-world projects:
- `14-todo-app` — Todo + localStorage
- `15-product-search` — product search + filter (API)
- `16-weather-app` — city weather (API)
- `17-github-profile-viewer` — GitHub profile (API)
