# 16 Weather App

## ภาษาไทย
พิมพ์ชื่อเมือง -> แปลงเป็นพิกัด (Geocoding) -> ดึงอากาศปัจจุบัน (Open-Meteo ไม่ต้องใช้ API key)

โน้ต: `fetch` 2 ต่อ, `encodeURIComponent`, `?.` กันพัง, `async/await` + `try/catch`

เปิด: `index.html` ใน browser (ต้องมีเน็ต)

## English
Type a city -> geocode to coordinates -> fetch current weather (Open-Meteo, no API key needed).

Note: chained `fetch`, `encodeURIComponent`, safe access with `?.`, `async/await` + `try/catch`

Open: `index.html` in a browser (needs internet)
