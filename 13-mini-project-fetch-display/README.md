# 13 Mini Project: Fetch + Display

## ภาษาไทย
เป้าหมาย portfolio: กด Reload -> fetch 5 posts -> แสดงเป็น list

โน้ตรวมยอด: `fetch` + `res.ok` + `map` + `createElement` + `addEventListener`

เปิด: `index.html` ใน browser (ดับเบิลคลิกไฟล์ได้เลย)

## English
Portfolio goal: press Reload -> fetch 5 posts -> render as list

Key points: `fetch` + `res.ok` + `map` + `createElement` + `addEventListener`

Open: `index.html` in a browser (just double-click the file)
